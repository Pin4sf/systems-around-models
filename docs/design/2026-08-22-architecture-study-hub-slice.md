# Architecture study hub — first public slice

Date: 2026-08-22

## Decision

Publish `/architectures` as the first edition of **The Big Agent Harness Architecture Comparison**. The route combines a beginner baseline, a shared comparison lesson, one wide matrix, and an anchored gallery generated from the same validated records.

The first cohort favors major coding harnesses, stateful runtimes, and memory systems. Specialist mechanisms can join later as supporting cases; they are not used as headline representatives merely because a detailed note exists.

## Reader contract

- Compare systems by job, control, state, authority, recovery, verification, and deliberate omission.
- Keep structural topology separate from lifecycle trace.
- Preserve unsupported responsibilities as delegated, external, or not established.
- Use no aggregate score and no universal leaderboard.
- Keep evidence grade, source validation, version, correction, and dossier status available but visually quiet.
- Use the same `ArchitectureRecord` for the matrix and gallery.

## First cohort

- Coding harnesses: Claude Code, OpenAI Codex, Gemini CLI, OpenHands.
- Stateful runtimes: LangGraph, Letta.
- Memory frameworks: Mem0, Graphiti.
- Teaching baseline: a six-responsibility conceptual harness, not a graded product.

These are working profiles rather than final dossiers. Source pins and unresolved questions are part of the publication contract so deeper implementation-primary research can improve a record without redesigning the reader.

## Impact surface

- Content contract: adds typed architecture and lesson records.
- Reader: adds one static architecture route and a small homepage/nav entrance.
- Publication: manifest v2 hashes architecture and lesson records and emits per-system manifests.
- Discovery: sitemap adds the architecture route; RSS remains the long-form essay feed.
- Release: privacy validation, expected static documents, bundle budget, and browser tests cover the new route.
- Runtime: remains fully server-rendered and ships zero client JavaScript.

## Deferred

- Dedicated system detail routes.
- Client-side filtering and sorting.
- A full Memory Systems Architecture Gallery.
- Specialist cases such as fleet custody and evidence pipelines.
- Waldo or Kennel as a general architecture assumption.
